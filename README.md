## Featured Projects

### 🛒 [E-Commerce Platform](https://github.com/sinembaglar/e-commerce-project) · [Live Demo](https://e-commerce-project-three-sand.vercel.app)

My graduation project: a responsive, multi-page e-commerce application covering the
whole shopping flow.

- Sign-up, login and token-based auto login, with protected routes for the order pages
- Product listing where category, sorting and filtering work together, plus pagination
- Shopping cart, a two-step checkout (address and card management) and order history
- State managed with Redux and Thunk; forms with React Hook Form

`React` `Redux` `Redux Thunk` `React Router` `React Hook Form` `Tailwind CSS` `Axios` `Vite`

### 🐦 [Twitter Clone API](https://github.com/sinembaglar/twitter-clone-backend)

A REST API for a Twitter-like application with tweets, comments, likes and retweets.

- Layered architecture: controller, service, repository, with DTOs for requests and responses
- Session-based authentication with Spring Security and BCrypt password hashing
- Ownership rules enforced in the service layer (only the owner can edit or delete a tweet)
- Global exception handling and Mockito unit tests for the service layer

`Java 17` `Spring Boot` `Spring Security` `Spring Data JPA` `PostgreSQL` `JUnit` `Mockito`
